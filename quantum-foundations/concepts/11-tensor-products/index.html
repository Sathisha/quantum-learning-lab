Back to basics: powers of two and binary

Two ideas from school do all the work today.

Powers of two. 2ⁿ means "multiply 2 by itself n times". Each time n goes up by 1, the answer doubles.

Binary counting. With only the digits 0 and 1, two digits can make exactly four labels: 00, 01, 10, 11. Read them as numbers: the left digit is worth 2, the right digit is worth 1.

2³ = 2 × 2 × 2 = 4 × 2 = 8 binary 10 = (1 × 2) + (0 × 1) = 2 + 0 = 2 binary 11 = (1 × 2) + (1 × 1) = 2 + 1 = 3

So the two-qubit labels 00, 01, 10, 11 are just the numbers 0, 1, 2, 3. That number is the label's position in the list (counting from 0).

The idea

One qubit is a list of 2 numbers: how much of |0⟩ and how much of |1⟩. Two qubits together are described by a list of 4 numbers, one for each label 00, 01, 10, 11. The tensor product ⊗ builds that 4-list from the two 2-lists: take each number of the first qubit and multiply it into the whole second qubit. Because every added qubit doubles the list, n qubits need 2ⁿ numbers, which is why big quantum states are so hard to store on a normal computer.

The key formula

(a, b) ⊗ (c, d) = (a·c, a·d, b·c, b·d)

Read it aloud: "The vector a, b, tensor the vector c, d, equals the vector: a times c, a times d, b times c, b times d."

The four slots, in order, belong to the labels |00⟩, |01⟩, |10⟩, |11⟩. With n qubits, the list has 2ⁿ slots.

Worked example: |+⟩ ⊗ |0⟩

Qubit 1 is |+⟩ = (1/√2, 1/√2), so a = 1/√2, b = 1/√2. Qubit 2 is |0⟩ = (1, 0), so c = 1, d = 0.

slot 1 (|00⟩): a·c = (1/√2) × 1 = 1/√2 slot 2 (|01⟩): a·d = (1/√2) × 0 = 0 slot 3 (|10⟩): b·c = (1/√2) × 1 = 1/√2 slot 4 (|11⟩): b·d = (1/√2) × 0 = 0 |+⟩ ⊗ |0⟩ = (1/√2, 0, 1/√2, 0) = (1/√2)|00⟩ + (1/√2)|10⟩ = (|00⟩ + |10⟩)/√2

In words: qubit 1 is a 50/50 mix, qubit 2 is surely 0. So only labels ending in 0 (00 and 10) appear.

Check: the probabilities must add up to 1.

(1/√2)² = 1 / (√2 × √2) = 1/2 0² = 0 1/2 + 0 + 1/2 + 0 = 1/2 + 1/2 = 1 ✓

Common mistakes

  • Swapping the order. ⊗ is not like ordinary ×. |0⟩⊗|1⟩ = (0, 1, 0, 0) = |01⟩, but |1⟩⊗|0⟩ = (0, 0, 1, 0) = |10⟩. So |0⟩⊗|1⟩ ≠ |1⟩⊗|0⟩.
  • Adding sizes instead of multiplying. Two 2-number vectors give 2 × 2 = 4 numbers, not 2 + 2. Three qubits give 2 × 2 × 2 = 8.
  • Qiskit reads labels backwards. On paper the left digit is the first qubit. Qiskit names qubits q0, q1, … and prints q0 on the right. When Qiskit shows "01", it means q0 = 1 and q1 = 0. You will meet this tomorrow.

Check question

Compute |0⟩ ⊗ |1⟩ (by hand, then with np.kron) and say which basis state it is.

Show answer

|0⟩ = (1, 0), so a = 1, b = 0. |1⟩ = (0, 1), so c = 0, d = 1.

slot 1 (|00⟩): a·c = 1 × 0 = 0 slot 2 (|01⟩): a·d = 1 × 1 = 1 slot 3 (|10⟩): b·c = 0 × 0 = 0 slot 4 (|11⟩): b·d = 0 × 1 = 0 |0⟩ ⊗ |1⟩ = (0, 1, 0, 0)

The only 1 sits in slot 2, whose label is 01. So |0⟩⊗|1⟩ = |01⟩: first qubit 0, second qubit 1. In binary, 01 = (0 × 2) + (1 × 1) = 1, which matches the position (#1, counting from 0).

Check: 0² + 1² + 0² + 0² = 0 + 1 + 0 + 0 = 1 ✓

Check it in NumPy

import numpy as np
ket0, ket1 = np.array([1, 0]), np.array([0, 1])
state = np.kron(ket0, ket1)
print(state)                 # [0 1 0 0]
print(np.argmax(state), format(np.argmax(state), "02b"))  # 1 01

Product state or entangled state

Product (separable)

Each qubit has its own state, and the pair can be written |a⟩ ⊗ |b⟩, shortened to |ab⟩.

|0⟩ ⊗ |1⟩ = |01⟩ = (0, 1, 0, 0)

Entangled

Cannot be written as |a⟩ ⊗ |b⟩ for any single-qubit states. The qubits are correlated, not independent. Example: (|00⟩ + |11⟩)/√2.

Try it: write |0⟩ ⊗ |1⟩ as a column
|0⟩ ⊗ |1⟩ = (1·|1⟩, 0·|1⟩) stacked = (1·0, 1·1, 0·0, 0·1) = (0, 1, 0, 0): the amplitude sits in slot "01" ✓
