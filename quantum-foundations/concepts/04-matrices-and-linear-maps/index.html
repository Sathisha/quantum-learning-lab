Linear algebra 2: matrices

A matrix is a grid of numbers that moves vectors around. Today you learn to read one, multiply with it, and flip it with the transpose and the dagger. Every quantum gate you meet later is one of these grids.

Back to basics

Today rests on two things you already met.

1. Sum of products (the inner products concept's dot product)

Line two lists up, multiply the matching pairs, then add the results. Times before plus: do every multiplication first.

Example: (2, 1) · (1, 3)
first pair: 2 · 1 = 2
second pair: 1 · 3 = 3
add them: 2 + 3 = 5
answer: 5

Every entry of a matrix product is one of these sums. If you can do this, you can multiply matrices.

2. The conjugate (the complex numbers concept)

To conjugate, keep the real part and flip the sign in front of i. A plain number with no i stays the same.

(3 − i)* = 3 + i
i* = −i
2* = 2 (no i part, nothing to flip)

The idea

A matrix is a machine that takes a vector in and gives a vector out. Each column tells you where one basis arrow lands: column 1 is where (1, 0) goes, column 2 is where (0, 1) goes. To compute the output, you take each row of the matrix and do a sum of products with the column vector. Two matrices can be multiplied only when the sizes line up, and the order matters.

When can you multiply? The size check

Write the two sizes side by side. The two inner numbers must match; the two outer numbers give the size of the answer.

(2 × 2) · (2 × 1) inner 2 = 2 → allowed, answer is 2 × 1
(2 × 3) · (3 × 2) inner 3 = 3 → allowed, answer is 2 × 2
(2 × 3) · (2 × 1) inner 3 ≠ 2 → not allowed

Picture 3: X swaps the axes

The matrix X = [[0, 1], [1, 0]] mirrors the plane across the diagonal line y = x. The two entries of every vector trade places. In quantum computing this same matrix is the NOT gate.

Three special moves

Identity I

I =1001

The "do nothing" matrix. I·v = v and I·A = A, just as 1 × 7 = 7.

Transpose Aᵀ

1234ᵀ =1324

Row 1 becomes column 1, row 2 becomes column 2. The diagonal (1 and 4) stays put; the other two swap.

Dagger A†

1i02† =10−i2

Transpose, then conjugate every entry. Here i moves to the bottom-left and becomes −i.

Key formula: matrix times vector

abcd · xy = a·x + b·yc·x + d·y

Read it aloud: "The matrix a, b; c, d times the vector x, y equals: a times x plus b times y on top, and c times x plus d times y underneath."

The general rule, for any sizes: the entry in row r, column c of A·B is row r of A dotted with column c of B.

Worked example: A·B, then B·A

A =1234B =0110

B is the swap matrix X from Picture 3.

Step 1: size check
A is 2 × 2, B is 2 × 2. Inner numbers: 2 and 2 match.
So A·B is allowed and is 2 × 2.
Step 2: row 1, column 1 (row 1 of A = (1, 2), column 1 of B = (0, 1))
1 · 0 = 0
2 · 1 = 2
0 + 2 = 2
Step 3: row 1, column 2 (row 1 of A = (1, 2), column 2 of B = (1, 0))
1 · 1 = 1
2 · 0 = 0
1 + 0 = 1
Step 4: row 2, column 1 (row 2 of A = (3, 4), column 1 of B = (0, 1))
3 · 0 = 0
4 · 1 = 4
0 + 4 = 4
Step 5: row 2, column 2 (row 2 of A = (3, 4), column 2 of B = (1, 0))
3 · 1 = 3
4 · 0 = 0
3 + 0 = 3
A·B = [[2, 1], [4, 3]]

Check. Compare with A = [[1, 2], [3, 4]]: the two columns of A have swapped places. That fits, because B sends column 1 to column 2 and back.

Now the other order. Doing the same four sums for B·A:

row 1 of B = (0, 1): 0·1 + 1·3 = 0 + 3 = 3 0·2 + 1·4 = 0 + 4 = 4
row 2 of B = (1, 0): 1·1 + 0·3 = 1 + 0 = 1 1·2 + 0·4 = 2 + 0 = 2
B·A = [[3, 4], [1, 2]]

This time the rows of A swapped. So A·B ≠ B·A: with matrices, order matters.

Common mistakes

  • Swapping the order. A·B and B·A are usually different, as the worked example shows. In a quantum circuit, the gate applied first sits on the right: B·A·v means "A first, then B".
  • Multiplying when the sizes don't fit. Always write the sizes side by side first. If the inner numbers differ, stop.
  • Half a dagger. A† needs both steps: transpose and conjugate. Only transposing, or only conjugating, is wrong. Also, conjugating flips only the sign of the i part: (3 − i)* is 3 + i, not −3 + i.

Practice

(a) Compute X·(a, b) for X = [[0, 1], [1, 0]].
(b) Find A† for A = [[1, i], [2, 3 − i]].

Show answer

(a) X·(a, b)

size check: (2 × 2) · (2 × 1), inner 2 = 2, answer is 2 × 1
top entry: row 1 of X = (0, 1) with (a, b)
0 · a = 0
1 · b = b
0 + b = b
bottom entry: row 2 of X = (1, 0) with (a, b)
1 · a = a
0 · b = 0
a + 0 = a
X·(a, b) = (b, a)

Check with numbers: a = 5, b = 7 gives (7, 5). The entries swapped, just like Picture 3.

(b) A† for A = [[1, i], [2, 3 − i]]

Step 1: transpose (rows become columns)
row 1 of A is (1, i) → becomes column 1
row 2 of A is (2, 3 − i) → becomes column 2
Aᵀ = [[1, 2], [i, 3 − i]]
Step 2: conjugate every entry (flip the sign of each i part)
1* = 1
2* = 2
i* = −i
(3 − i)* = 3 + i
A† = [[1, 2], [−i, 3 + i]]
A† =12−i3 + i

Check: take the dagger again. Transpose gives [[1, −i], [2, 3 + i]]; conjugating gives [[1, i], [2, 3 − i]], which is A again. Doing the dagger twice always brings you back.

Check it in NumPy

@ is NumPy's matrix multiply, 1j is how Python writes i, and .conj().T is the dagger.

import numpy as np
X = np.array([[0, 1], [1, 0]])
print(X @ np.array([5, 7]))        # [7 5]  -> (b, a)
A = np.array([[1, 1j], [2, 3 - 1j]])
print(A.conj().T)                  # [[1, 2], [-1j, 3+1j]]
