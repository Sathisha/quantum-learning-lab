Real → complex: what changes

Most linear algebra we learnt was over the real numbers. Quantum computing runs over the complex numbers, and almost every rule we know has a complex version with one extra conjugate in it. This page lists each real habit next to its complex replacement, then lines up the three notations used in class (bold vectors, Dirac kets, NumPy) so you can translate between them.

The one rule behind everything

For a real number, x · x = x² is never negative, so it works as a "size squared". For a complex number it fails: i · i = −1. The fix is to multiply by the conjugate instead:

|z|² = z̄ · z = a² + b² (z = a + bi)
z = 3 + 4i: z · z = 9 + 24i + 16i² = −7 + 24i ✗ not a size z̄ · z = (3 − 4i)(3 + 4i) = 9 + 16 = 25 ✓ |z| = 5
Every rule on this page is this same fix applied again. Wherever real linear algebra "multiplies a thing by itself" to get a length, an angle or a probability, the complex version conjugates one of the two copies.

Worked example, every step shown: are c₊ and c₋ orthogonal?

c₊ = (1, i)/√2 and c₋ = (1, −i)/√2, also written |+i⟩ and |−i⟩. On the Bloch sphere they are opposite ends of the y-axis, so they must be orthogonal.

Real habit (no conjugate)
½ [1·1 + i·(−i)] = ½ [1 − i²] = ½ [1 + 1] = 1

This says they are the same state, which is nonsense.

Complex rule (conjugate the first)
½ [conj(1)·1 + conj(i)·(−i)] = ½ [1 + (−i)(−i)] = ½ [1 + i²] = ½ [1 − 1] = 0 ✓

Orthogonal, as the picture says.

Notice why the real habit usually goes unnoticed: for |0⟩, |1⟩, |+⟩ and |−⟩ all the entries are real, and conjugating a real number does nothing. The mistake only shows once an i appears.

NumPy's four "dot" functions, and which one conjugates:
  • np.vdot(u, v): conjugates u. This is ⟨u, v⟩.
  • u @ v, np.dot(u, v), np.inner(u, v): no conjugate. For u = (1, i), u @ u gives 0, while np.vdot(u, u) gives 2.
  • A.T is the transpose; A.conj().T is the dagger.
  • z**2 is z²; abs(z)**2 is |z|².

Convention clashes between books

  • Which slot is conjugated. This course and physics books conjugate the first vector: ⟨u, v⟩ = Σ ūkvk. Many maths books conjugate the second. The two answers are conjugates of each other, so |⟨u, v⟩| and orthogonality agree; just never mix the two in one calculation.
  • Angles on the Bloch sphere. θ is measured down from the north pole (the z-axis), not up from the x-axis as on the unit circle. φ is measured round the equator starting from the x-axis.
  • The half angle. The amplitudes use θ/2: cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩. Opposite points on the sphere (180° apart) are orthogonal vectors (90° apart). Why.
  • i or j. Electrical engineers write j for √−1, and Python writes 1j.
  • "Orthogonal". For vectors it means ⟨u, v⟩ = 0. An "orthogonal matrix" is the real cousin of a unitary one.
  • ψ vs |ψ⟩. Both name the same state vector. The ket brackets just flag that it is a column you can put a bra in front of.

Common mistakes

  • Squaring an amplitude instead of taking |·|²: (i/√2)² = −1/2, but the probability is |i/√2|² = 1/2.
  • Forgetting to conjugate when writing a bra: ⟨−i| = (1, +i)/√2.
  • Calling a matrix Hermitian because it is symmetric. Symmetric with complex entries, like [[0, i], [i, 0]], is not Hermitian.
  • Using @ or np.dot for an inner product of complex vectors.
  • Reading |01⟩ from Qiskit's printout as "qubit 0 is 0".

Check it in NumPy

import numpy as np
cp, cm = np.array([1, 1j])/np.sqrt(2), np.array([1, -1j])/np.sqrt(2)
print(cp @ cm, np.vdot(cp, cm))          # (1+0j) wrong habit,  0j correct
A = np.array([[2, 1+1j], [1-1j, 3]])
print(np.allclose(A, A.conj().T), np.allclose(A, A.T))   # True False
u, v = np.array([1j, 1]), np.array([2, 1j])
a = 2 + 3j
print(np.isclose(np.vdot(a*u, v), np.conj(a)*np.vdot(u, v)))  # True: conjugated on the way out
