Probability and Expectation
Concept 06

the probability concept: Probability: distributions and expectation

Today joins the complex numbers concept (complex numbers) to chance. A qubit's amplitudes are complex numbers; squaring their size gives the odds of each measurement result.

Back to basics: the three probability rules

A fair die has 6 equally likely faces, so each face has probability 1/6. Probability of an event = (number of ways it can happen) ÷ (total number of equally likely outcomes).

NOT: P(not A) = 1 − P(A)

P(roll a 6) = 1/6
P(not a 6) = 1 − 1/6
= 6/6 − 1/6
= 5/6 ≈ 0.833

OR: P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Subtract the overlap so it isn't counted twice. If A and B can't both happen, the overlap is 0 and you just add.

P(1 or 2) = P(1) + P(2) − P(1 and 2)
= 1/6 + 1/6 − 0 (one roll can't be both)
= 2/6
= 1/3 ≈ 0.333

AND (independent events): P(A ∩ B) = P(A) · P(B)

P(coin heads and die 6) = P(heads) · P(6)
= 1/2 · 1/6
= (1·1)/(2·6)
= 1/12 ≈ 0.083

One more refresher from the complex numbers concept: size squared of a complex number

z = a + bi → |z|² = a² + b²
Example z = i/√2: a = 0, b = 1/√2
|z|² = 0² + (1/√2)²
= 0 + 1/2
= 1/2

The idea

A distribution lists every possible outcome with its probability, and those probabilities must add up to exactly 1 (something always happens). The expected value multiplies each outcome's value by its probability and adds the results: it is the average you would see over many repeats, and the point where the bar chart would balance. Variance measures how far results typically land from that average. In quantum computing, a qubit carries complex amplitudes α and β; measuring it gives outcome 0 with probability |α|² and outcome 1 with probability |β|², and these always sum to 1.

Diagrams

1. Amplitudes (arrows) → probabilities (bars) → balance point

Left: the two amplitudes drawn on the complex plane with the unit circle (radius 1). Right: each arrow's length squared becomes a bar. Below: outcome 0 is scored +1 and outcome 1 is scored −1; the triangle sits at the expected value, where the seesaw balances. It starts on today's worked example, α = 3/5 and β = 4i/5.

2. Expected value as the balance point

A general distribution: values 1, 2, 3, 4 with probabilities 0.1, 0.2, 0.3, 0.4. Picture each bar as a weight on a plank. The plank balances at E[X] = 3.0.

Key formula

E[X] = Σ xᵢ · pᵢ
with pᵢ = |αᵢ|² and Σ pᵢ = 1
Read it aloud: "E of X equals the sum, over every outcome i, of x sub i times p sub i. Here p sub i is mod alpha sub i squared, and the sum of all the p sub i's equals one." In plain words: multiply each value by its chance, add them up; each chance is an amplitude's size squared; the chances add to 1.

Worked example

A qubit has amplitudes α = 3/5 (outcome 0) and β = 4i/5 (outcome 1). Outcome 0 scores +1, outcome 1 scores −1. Find the probabilities, the expected value and the variance.

Step 1: probability of outcome 0

α = 3/5 = 3/5 + 0i (a = 3/5, b = 0)
|α|² = (3/5)² + 0²
= (3·3)/(5·5) + 0
= 9/25
= 0.36

Step 2: probability of outcome 1

β = 4i/5 = 0 + (4/5)i (a = 0, b = 4/5)
|β|² = 0² + (4/5)²
= 0 + (4·4)/(5·5)
= 16/25
= 0.64

Step 3: check they sum to 1

9/25 + 16/25 = (9 + 16)/25
= 25/25
= 1 ✓ a valid distribution

Step 4: expected value

E[X] = (+1)·0.36 + (−1)·0.64
= 0.36 + (−0.64)
= 0.36 − 0.64
= −0.28

Step 5: variance, Var(X) = E[X²] − (E[X])²

X² values: (+1)² = 1 and (−1)² = 1
E[X²] = 1·0.36 + 1·0.64
= 0.36 + 0.64
= 1
(E[X])² = (−0.28)² = (−0.28)·(−0.28) = 0.0784
Var(X) = 1 − 0.0784
= 0.9216
σ = √0.9216 = 0.96 (since 0.96 · 0.96 = 0.9216)

Check

Variance the long way, Var = Σ (xᵢ − μ)² · pᵢ, with μ = −0.28:
(+1 − (−0.28))² · 0.36 = (1.28)² · 0.36 = 1.6384 · 0.36 = 0.589824
(−1 − (−0.28))² · 0.64 = (−0.72)² · 0.64 = 0.5184 · 0.64 = 0.331776
Sum = 0.589824 + 0.331776 = 0.9216 ✓ matches Step 5
Sense check: E = −0.28 is negative because outcome 1 (score −1) is more likely. ✓

Common mistakes

  • Squaring the amplitude instead of its size. (4i/5)² = 16i²/25 = −16/25, a negative "probability". Square the modulus: |4i/5|² = 16/25.
  • Forgetting the probabilities must add to 1. Always check Σ pᵢ = 1. If amplitudes (1, 1) give 1 + 1 = 2, the state was not normalised: divide each by √2.
  • Expecting to see the expected value. E[X] = −0.28 never appears on a single measurement; each shot gives +1 or −1. It is the average over many shots.

Practice question

A qubit has amplitudes α = 1/√2 (outcome 0, scored +1) and β = i/√2 (outcome 1, scored −1). Give each outcome's probability and the expected value.

Show answer

Probability of outcome 0

α = 1/√2 + 0i (a = 1/√2, b = 0)
|α|² = (1/√2)² + 0²
= 1²/(√2)²
= 1/2 (because √2 · √2 = 2)
= 0.5

Probability of outcome 1

β = 0 + (1/√2)i (a = 0, b = 1/√2)
|β|² = 0² + (1/√2)²
= 1/2
= 0.5
Same via the conjugate: β·β* = (i/√2)(−i/√2) = −i²/2 = −(−1)/2 = 1/2

Check the sum

0.5 + 0.5 = 1 ✓

Expected value

E[X] = (+1)·0.5 + (−1)·0.5
= 0.5 − 0.5
= 0

Answer: P(0) = 1/2, P(1) = 1/2, E[X] = 0. The i in β changes only the phase (direction of the arrow), not its length, so it has no effect on these probabilities. Bonus: Var(X) = E[X²] − 0² = (1·0.5 + 1·0.5) − 0 = 1, the largest spread possible for ±1 outcomes. Set θ = 45° and φ = 90° in Diagram 1 to see this state.

Check it in NumPy

import numpy as np
amp = np.array([1/np.sqrt(2), 1j/np.sqrt(2)])   # α, β
p = np.abs(amp)**2                               # |α|², |β|²
print(p, p.sum())                                # [0.5 0.5] 1.0
print(np.dot([+1, -1], p))                       # E[X] = 0.0
