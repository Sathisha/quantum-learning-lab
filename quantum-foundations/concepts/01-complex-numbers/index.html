Complex numbers

Every qubit is described by complex numbers. This page shows how to read them, draw them, turn them into an angle and a length, and why their angles (phases) make interference possible.

Back to basics

Pythagoras. In a right-angled triangle with short sides a and b, the long side (hypotenuse) c obeys c² = a² + b², so c = √(a² + b²).

Sine and cosine (SOH CAH TOA). For the angle θ at one corner: sin θ = opposite ÷ hypotenuse, cos θ = adjacent ÷ hypotenuse, tan θ = opposite ÷ adjacent.

Degrees and radians. 180° = π rad, so 90° = π/2, 45° = π/4.

Tiny example: a triangle with sides a = 3 (across) and b = 4 (up). c = √(3² + 4²) = √(9 + 16) = √25 = 5 sin θ = opposite ÷ hypotenuse = 4 ÷ 5 = 0.8 cos θ = adjacent ÷ hypotenuse = 3 ÷ 5 = 0.6 check: 0.6² + 0.8² = 0.36 + 0.64 = 1 ✓

The idea

No ordinary number squares to give −1, so mathematicians invented one, called i, and declared i² = −1. A complex number a + bi is then just a point on a flat plane: a steps across, b steps up. You can describe the same point a second way, by its length r and its angle θ. Quantum computing uses both descriptions all the time, and Euler's formula is the bridge between them.

Pictures

Key formula

e^(iθ) = cos θ + i·sin θ
Read it aloud: "e to the i theta equals cos theta plus i sine theta."
so any z = a + bi can be written z = r·e^(iθ), with r = |z| = √(a² + b²)
Read it aloud: "zed equals r e to the i theta, where r, the mod of zed, is the square root of a squared plus b squared."

Why is Euler's formula true? (optional)

You can use e^(iθ) = cos θ + i sin θ without proving it. If you want to see why, the reason is the "Taylor series" of eˣ: an endless sum that equals eˣ for every x.

eˣ = 1 + x + x²/2! + x³/3! + x⁴/4! + … n! ("n factorial") means 1 × 2 × … × n. So 2! = 2, 3! = 6, 4! = 24. Put x = iθ. The powers of i repeat: i⁰ = 1, i¹ = i, i² = −1, i³ = −i, i⁴ = 1, … e^(iθ) = 1 + iθ − θ²/2! − iθ³/3! + θ⁴/4! + … Terms without i: 1 − θ²/2! + θ⁴/4! − … = cos θ Terms with i (take the i out): θ − θ³/3! + θ⁵/5! − … = sin θ e^(iθ) = cos θ + i sin θ ✓

The two grouped sums are the Taylor series of cos and sin. Try θ = π: cos π + i sin π = −1 + 0i, which gives the famous e^(iπ) = −1.

Worked example: z = 3 + 4i

1. Real and imaginary parts a = 3, b = 4 2. Conjugate: flip the sign of b z̄ = 3 − 4i 3. Modulus (length) by Pythagoras |z| = √(a² + b²) = √(3² + 4²) = √(9 + 16) = √25 = 5 4. Angle (a is positive, so arctan gives the right angle) θ = arctan(b ÷ a) = arctan(4 ÷ 3) = arctan(1.3333…) ≈ 0.9273 rad ≈ 0.9273 × (180 ÷ π)° ≈ 53.13° 5. Polar form z = 5·(cos 53.13° + i·sin 53.13°) = 5·e^(i·0.9273) Check 1: turn the polar form back into a + bi 5 × cos 53.13° = 5 × 0.6 = 3 ✓ (that's a) 5 × sin 53.13° = 5 × 0.8 = 4 ✓ (that's b) Check 2: z times its conjugate should be |z|² (3 + 4i)(3 − 4i) = 3·3 + 3·(−4i) + 4i·3 + 4i·(−4i) = 9 − 12i + 12i − 16i² = 9 − 16·(−1) (because i² = −1) = 9 + 16 = 25 = 5² ✓

Multiplying in polar form: lengths multiply, angles add

Polar form makes multiplication easy. Write z₁ = r₁e^(iθ₁) and z₂ = r₂e^(iθ₂). The power rule e^a · e^b = e^(a+b) works for complex powers too:

z₁ · z₂ = r₁r₂ · e^(i(θ₁ + θ₂))

Read it aloud: "z one times z two equals r one r two, e to the i, theta one plus theta two". Multiply the lengths, add the angles.

Example: (1 + i) · (1 + i√3) 1 + i: length √(1 + 1) = √2, angle 45° 1 + i√3: length √(1 + 3) = 2, angle 60° (angle = arctan(√3 ÷ 1) = 60°) Product: length √2 × 2 = 2√2 ≈ 2.828 angle 45° + 60° = 105° Check the long way, using i² = −1: (1 + i)(1 + i√3) = 1 + i√3 + i + i²√3 = (1 − √3) + i(1 + √3) ≈ −0.732 + 2.732i 2.828 × cos 105° = 2.828 × (−0.259) ≈ −0.732 ✓ 2.828 × sin 105° = 2.828 × 0.966 ≈ 2.732 ✓

Three consequences you will use all the time

  • Multiplying by e^(iφ) is a pure rotation. Its length is 1, so lengths don't change; the angle just grows by φ. Multiplying by i (= e^(iπ/2)) turns by 90°, by −1 (= e^(iπ)) by 180°.
  • Powers: zⁿ = rⁿ · e^(inθ) ("De Moivre"). Example: (1 + i√3)⁶ has length 2⁶ = 64 and angle 6 × 60° = 360°, a full turn, so it equals 64.
  • Dividing: lengths divide, angles subtract. 1/e^(iθ) = e^(−iθ), which is also the conjugate of e^(iθ).

Negative angles turn clockwise. e^(−iπ/6) is the point 30° below the real axis: cos 30° − i sin 30° = 0.866 − 0.5i.

Roots of unity

"Unity" means 1. The n-th roots of unity are the n numbers z with zⁿ = 1. In polar form the length must be 1 (since 1ⁿ = 1), and n times the angle must be a whole number of full turns. So the angles are 0, 1/n, 2/n, … of a full turn:

z = e^(2πik/n), k = 0, 1, …, n − 1

Read it aloud: "e to the two pi i k over n". Write ω = e^(2πi/n) ("omega"); then the roots are 1, ω, ω², …, ω^(n−1), evenly spaced around the unit circle.

n = 4: angles 0°, 90°, 180°, 270° → 1, i, −1, −i Check i: i⁴ = (i²)² = (−1)² = 1 ✓

For n ≥ 2 the roots add up to zero. Place the arrows head to tail and you come back to the start.

n = 3: ω = e^(2πi/3) = cos 120° + i sin 120° = −1/2 + i√3/2 ω² = e^(4πi/3) = −1/2 − i√3/2 1 + ω + ω² = (1 − 1/2 − 1/2) + i(√3/2 − √3/2) = 0 + 0i Sum = 0 In general 1 + ω + … + ω^(n−1) = (ωⁿ − 1)/(ω − 1), the geometric-series formula, and ωⁿ − 1 = 0.

Solving zⁿ = c. Take one answer and multiply it by each n-th root of unity. Example z⁴ = 2: one answer is 2^(1/4) ≈ 1.189, so all four are 1.189, 1.189i, −1.189 and −1.189i.

Quantum link: the cancelling sum is the heart of the quantum Fourier transform, the engine of Shor's algorithm. Practice Q8 is the n = 5 case.

Phase and interference

A phase is a complex number of size 1: e^(iφ) = cos φ + i sin φ. Picture it as an arrow of length 1 pointing at angle φ ("phi"). From the section above, multiplying by a phase only rotates. It never changes a size.

Adding is different. Take two arrows of length 1, the number 1 and e^(iφ), and add them tip to tail. Pointing the same way, they make length 2. Pointing opposite ways, they cancel to 0. In between, anything in between.

1 + e^(iφ) = (1 + cos φ) + i·sin φ Real part 1 + cos φ, imaginary part sin φ. Size squared = real² + imaginary²: |1 + e^(iφ)|² = (1 + cos φ)² + sin² φ = 1 + 2cos φ + cos² φ + sin² φ = 1 + 2cos φ + 1 because cos² φ + sin² φ = 1 |1 + e^(iφ)|² = 2 + 2cos φ

Why the size squared? In quantum computing a probability is an amplitude's size squared, so this is the number that ends up mattering.

φcos φ2 + 2cos φWhat happens
014Arrows aligned: they reinforce (constructive interference)
π/2 (90°)02Arrows at right angles: sum length √2
2π/3 (120°)−1/21The pink dot (practice Q7)

Both arrows have size 1 in every row. Only the angle between them changes, yet the result runs from 0 to 4. That is interference.

Global phase: you can't measure it

A global phase multiplies every number in a state by the same e^(iθ). It turns all the arrows by the same angle, so the angle between any two arrows is unchanged, and so is every sum and every size.

ψ = (1/√2, 1/√2) iψ = (i/√2, i/√2) |i/√2|² = |i|² · (1/√2)² = 1 · 1/2 = 1/2 Same as |1/√2|² = 1/2. Same probabilities, in every basis ψ and iψ are the same physical state.

Relative phase: you can measure it

A relative phase sits on only one part of a state. Compare (1, 1)/√2 and (1, −1)/√2, where −1 = e^(iπ):

  • Square each entry separately (the 0/1 measurement): |1/√2|² = |−1/√2|² = 1/2. Both give 50/50, so the minus sign is invisible.
  • Add the entries first (the ± measurement, which compares the state with (1, 1)/√2): now the graph above appears.
State (1, e^(iφ))/√2. Its overlap with (1, 1)/√2: (1/√2)(1/√2) · (1 + e^(iφ)) = ½ (1 + e^(iφ)) Probability = size squared, and the graph gives |1 + e^(iφ)|²: P(+) = ¼ · |1 + e^(iφ)|² = ¼ (2 + 2cos φ) = (1 + cos φ)/2 φ = 0: P(+) = (1 + 1)/2 = 1, "+" every time φ = π: P(+) = (1 − 1)/2 = 0, "−" every time

Two states that look identical one way are perfectly distinguishable the other way. The overlap uses the inner product (inner products), and qubit states and the ± measurement are on qubits and the Bloch sphere.

Why this matters: every quantum algorithm works by arranging phases so that the arrows leading to wrong answers point opposite ways and cancel. Deutsch's algorithm is exactly this graph with φ set to 0 or π.

Try it: for (1, i)/√2, what is P(+)?
i = e^(iπ/2), so φ = π/2 P(+) = (1 + cos 90°)/2 = (1 + 0)/2 = 1/2 The middle of the curve: 50/50 in the ± measurement too.

Common mistakes

  • Forgetting i² = −1. In (3 + 4i)(3 − 4i) the last term is −16i², which is +16, not −16. The answer is 25, not −7.
  • Putting the i inside the modulus. |3 + 4i| uses only the numbers a = 3 and b = 4: √(9 + 16) = 5. Never √(9 + (4i)²) = √(9 − 16).
  • Degrees vs radians, and the wrong quadrant. NumPy's np.angle returns radians (0.9273, not 53.13). And arctan(b ÷ a) alone is only right when a is positive; for a point on the left half (a negative), add 180°. Draw the point first and look.
  • Thinking a negative angle is impossible. −θ just means clockwise: e^(−iπ/6) is 30° below the real axis.
  • Adding angles when you add numbers. Angles add when you multiply. Adding two numbers is tip-to-tail arrows, and the result depends on the angle between them.
  • Treating every phase as meaningless. A phase on the whole state (global) changes nothing you can measure. A phase on one part only (relative) changes interference.

Check it in NumPy

Python writes i as 1j.

import numpy as np
z = (1 + 1j) / np.sqrt(2)
print(abs(z))                              # 1.0 (modulus)
print(np.angle(z), np.pi / 4)              # 0.785398... both (radians)
print(np.isclose(z, np.exp(1j * np.pi/4))) # True
