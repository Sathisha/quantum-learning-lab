eiθ and phase

eiθ is the single most used expression in quantum computing. It is not exponential growth: it is a point on the unit circle at angle θ, and multiplying by it turns a complex number by θ. Once that clicks, phases, phase gates, global vs relative phase and the complex eigenvalues of rotations all become the same idea.

Back to basics: exponent rules

For ordinary numbers you know these rules. The surprise is that all three still hold when the exponent is imaginary. That is what makes eiθ so convenient.

e^a · e^b = e^(a+b) multiply → add exponents (e^a)^n = e^(na) power → multiply exponent (n a whole number) e^0 = 1 1 / e^a = e^(−a)

The complex numbers page has the reason Euler's formula is true (put iθ into the series for ex). Here we only use it.

The idea: a direction you can multiply

eiθ = cos θ + i sin θ

Say: "e to the i theta is cos theta plus i sine theta."

The real part is cos θ and the imaginary part is sin θ. That is exactly the point at angle θ on the unit circle, now read as a complex number. Any complex number can be written as length × direction:

z = r · eiθ (r = |z|, θ = arg z)

Multiplying by eiθ keeps the length and adds θ to the angle: it rotates. Try it: set two angles and watch the product land at their sum.

Read the most famous line, eiπ = −1, as "half a turn points the opposite way". So a minus sign is a phase of π. Every (−1)f(x) in Deutsch's algorithm is eiπf(x).

Multiply = add angles, and the trig formulas come free

The exponent rule eia·eib = ei(a+b) holds. Expand both sides and compare real and imaginary parts:

left: (cos a + i sin a)(cos b + i sin b) = cos a cos b + i cos a sin b + i sin a cos b + i² sin a sin b = (cos a cos b − sin a sin b) + i (sin a cos b + cos a sin b) (i² = −1) right: cos(a+b) + i sin(a+b) Real parts match: cos(a+b) = cos a cos b − sin a sin b Imaginary parts match: sin(a+b) = sin a cos b + cos a sin b
You never need to memorise the addition formulas again. Multiply two eiθ's and read them off.

Compute eiπ/3 · eiπ/6 both ways.

Careful with fractional powers. Because angles repeat every 2π, "the square root of eiθ" has two answers, eiθ/2 and −eiθ/2. Whole-number powers are always safe.

Getting cos and sin back out

Add and subtract eiθ and e−iθ. The sine parts cancel in the sum, and the cosine parts cancel in the difference:

cos θ = (eiθ + e−iθ)/2 · sin θ = (eiθ − e−iθ)/(2i)

This is interference in miniature: two arrows that turn in opposite directions add up to something purely real. It comes back in Deutsch's algorithm, where the amplitude of |0⟩ is (−1)f(0) + (−1)f(1), so it is either ±2 (the arrows agree) or 0 (they cancel).

Phase on a qubit: global vs relative

A qubit is α|0⟩ + β|1⟩ with complex α, β. Write each amplitude as length × phase. Only two things can then happen to the phases:

Global phase: invisible

eiγ(α|0⟩ + β|1⟩)

Every amplitude turns by the same γ. All probabilities |eiγα|² = |α|² are unchanged in every basis, so it is the same physical state. Example: −|ψ⟩ ≡ |ψ⟩ (γ = π).

Relative phase: real and measurable

α|0⟩ + eiφβ|1⟩

Only one amplitude turns. The Z-basis probabilities stay the same, but measurements in other bases change. |+⟩ and |−⟩ differ only by φ = π: both are 50/50 in Z, but H sends them to |0⟩ and |1⟩.

On the Bloch sphere, the relative phase φ is the longitude: cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩. Global phase has no place on the sphere at all, which is why one qubit needs only two angles (Bloch sphere page).

eiθ as an eigenvalue

The rotation matrix Rθ turns every real arrow, so it has no real eigenvector. Over ℂ its eigenvalues are e+iθ and e−iθ (worked on the eigenvalues page). This is a general pattern:

Every eigenvalue of a unitary matrix is a pure phase eiα. A unitary never changes lengths, so if Uv = λv then ‖v‖ = ‖λv‖ = |λ|·‖v‖, which forces |λ| = 1. For the gates: X, Z, H have eigenvalues ±1 = ei0, eiπ; S has 1, i; T has 1, eiπ/4.

The difference between a gate's two eigenvalue phases is the angle it turns the Bloch sphere through, about the axis through its eigenvectors. Page 13 puts this together.

Roots of unity: equal steps round the circle

The n solutions of zⁿ = 1 are the powers of ω = e2πi/n: n points spaced evenly round the circle. Their sum is 0, because the arrows balance:

n = 4: ω = e^(iπ/2) = i 1 + i + (−1) + (−i) = 0 n = 2: ω = e^(iπ) = −1 1 + (−1) = 0 ← the cancellation in Deutsch–Jozsa

This balancing is the heart of the quantum Fourier transform later in the course.

Common mistakes

  • Treating eiθ as growth. |eiθ| = 1 whatever θ is. Only a real exponent grows.
  • Adding states is not adding angles. eia · eib = ei(a+b), but eia + eib is a different number with length between 0 and 2.
  • Calling a global phase a change. −|0⟩ and |0⟩ are the same state. (|0⟩ − |1⟩)/√2 and (|0⟩ + |1⟩)/√2 are not: that sign is relative.
  • Forgetting to flip phases in a bra. ⟨+i| = (1, −i)/√2, not (1, i)/√2.
  • Comparing angles without the 2π wrap. −π/2 and 3π/2 are the same phase. NumPy's np.angle always reports values between −π and π.

  3. Write z = −1 − i as r·eiθ.

Show worked solutions
1. 3π/4 + π/4 = π → e^(iπ) = −1 2. |z|² = z · conj(z) = e^(iθ) · e^(−iθ) = e^0 = 1 3. r = √((−1)² + (−1)²) = √2. The point is in quadrant III at 225° = 5π/4. z = √2 · e^(i5π/4) (or √2·e^(−i3π/4): the same angle, wrapped) 4. i = e^(iπ/2) multiplies both terms: a global phase, so the same state as |+⟩. (|0⟩ + i|1⟩)/√2 has a relative phase π/2: it is |+i⟩, a different state.

Check it in NumPy

import numpy as np
e = lambda t: np.exp(1j*t)
print(e(np.pi/3)*e(np.pi/6))                 # ≈ 1j
print(abs(e(1.234)))                          # 1.0
print(np.angle(-1-1j), -3*np.pi/4)            # same: np.angle reports (−π, π]
S, Z, T = np.diag([1, 1j]), np.diag([1, -1]), np.diag([1, e(np.pi/4)])
print(np.allclose(S@S, Z), np.allclose(T@T, S))   # True True
R = lambda t: np.array([[np.cos(t), -np.sin(t)], [np.sin(t), np.cos(t)]])
print(np.linalg.eigvals(R(0.7)), e(0.7), e(-0.7)) # eigenvalues are e^(±0.7i)
