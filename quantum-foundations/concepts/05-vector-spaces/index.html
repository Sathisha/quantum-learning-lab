Concept 05 · Part B · Linear algebra

Vector spaces over ℂ

What you can build by adding vectors and scaling them by complex numbers. Span, subspaces, linear independence, basis and dimension come up in every later topic: in quantum computing every measurement is a choice of basis, so you will be dealing with bases all the time. If orthonormal bases (the next concept) feel shaky, this is the page to come back to.

Back to basics: adding and scaling columns

A vector here is just a column of numbers. Two moves are allowed, and both work entry by entry:

  • Add two vectors: add matching entries.
  • Scale a vector by a number α: multiply every entry by α. With complex α this can rotate the entries, not just stretch them.
u = (1, 2i), v = (3, −i) u + v = (1 + 3, 2i − i) = (4, i) i·u = (i·1, i·2i) = (i, 2i²) = (i, −2) because i² = −1 2u − v = (2 − 3, 4i + i) = (−1, 5i)

The idea

  • ℂⁿ is columns of n complex numbers. You add them entry by entry and scale them by complex numbers.
  • Linear combination: α₁v₁ + … + α_kv_k. A quantum superposition is exactly this.
  • Independent: no vector is a combination of the others. Each one adds a new direction.
  • Basis: independent and spanning, so every vector has unique coordinates. Their count is the dimension.

All pictures are drawn in ℝ² because ℂ² needs four real dimensions. The algebra is what carries over.

Span and subspaces

A linear combination of v₁ … v_k is α₁v₁ + … + α_kv_k with complex numbers αⱼ. The span is the set of every such combination. A quantum superposition is exactly a linear combination: α|0⟩ + β|1⟩ is α·e₁ + β·e₂.

A subspace is a subset you can't leave by adding or scaling. Every span is a subspace, and every subspace contains 0, so a quick test is "does it contain the zero vector?"

Is S = {(z₁, z₂) : z₂ = z₁ + 1} a subspace of ℂ²? Zero test: put z₁ = 0 → z₂ = 0 + 1 = 1, so (0, 0) is not in S. Not a subspace (no zero vector). Compare T = {(z₁, z₂) : z₂ = 2i·z₁}: (0, 0) is in T, and adding or scaling keeps z₂ = 2i·z₁. T = span{(1, 2i)} ✓
Practice: is {(z₁, z₂) : z₁ · z₂ = 0} a subspace of ℂ²?
It contains (0, 0), so the zero test passes. Now test adding: (1, 0) is in it (1·0 = 0). (0, 1) is in it (0·1 = 0). (1, 0) + (0, 1) = (1, 1), and 1·1 = 1 ≠ 0. Not a subspace: passing the zero test isn't enough.

Linear independence, and the complex twist

v₁ … v_k are linearly independent if the only way to get α₁v₁ + … + α_kv_k = 0 is with every α = 0. Otherwise one of them is a combination of the others and adds nothing new to the span.

The twist: the answer depends on which numbers you may scale by. In ℂⁿ, "parallel" means "a complex multiple", so vectors that look different can point the same way.

u = (1, 2i), w = (i, −2). Is w a multiple of u? First entries: i = c · 1 → c = i Check second: c · 2i = i · 2i = 2i² = −2 ✓ matches w w = i·u → dependent over ℂ. Over ℝ (real c only): c = i isn't allowed, and no real c works → independent over ℝ.

Quantum link: w = i·u is the global-phase idea. ψ and e^{iφ}ψ are "the same direction", which is why they are the same physical state (phases, on the complex numbers page).

Practice: are (1, 1+i) and (1−i, 2) independent over ℂ?
Try (1−i, 2) = c·(1, 1+i). First entry: c = 1 − i. Second entry: c(1+i) = (1−i)(1+i) = 1 − i² = 2 ✓ Dependent over ℂ: (1−i, 2) = (1−i)·(1, 1+i).

Basis and dimension: always ask "over which numbers?"

A basis is an independent set that spans the space. Every vector then has unique coordinates, and every basis has the same size: the dimension.

ℂ² over ℂ: basis {e₁, e₂}. (a+bi, c+di) = (a+bi)e₁ + (c+di)e₂ → dim 2 ℂ² over ℝ: coefficients must be real, so you need {e₁, i·e₁, e₂, i·e₂}: (a+bi, c+di) = a·e₁ + b·(i e₁) + c·e₂ + d·(i e₂) → dim 4 dim over ℂ = n, dim over ℝ = 2n

n qubits live in ℂ^(2ⁿ): 1 qubit → 2, 2 qubits → 4, 10 qubits → 1,024, 50 qubits → about 10¹⁵. (See tensor products.)

Worked example: coordinates in a basis

A basis gives every vector one set of coordinates. Finding them means solving "which combination makes this vector?"

Find the coordinates of v = (3, i) in the basis b₁ = (1, i), b₂ = (1, −i).

Want α·b₁ + β·b₂ = v α(1, i) + β(1, −i) = (3, i) Top entries: α + β = 3 Bottom entries: iα − iβ = i Divide both sides by i: α − β = 1 Add the two equations: 2α = 4. α = 2, β = 3 − 2 = 1 Check: 2(1, i) + 1(1, −i) = (2 + 1, 2i − i) = (3, i) ✓ Coordinates (2, 1) in this basis; (3, i) in the standard basis

Same vector, different coordinates in different bases. With an orthonormal basis you don't need to solve equations at all: each coordinate is one inner product (inner products and bases). b₁ and b₂ here happen to be perpendicular: divided by √2 they are the "circular" basis.

Common mistakes

  • Calling a shifted line a subspace. Every subspace contains the zero vector, so a line that misses the origin is not one.
  • Stopping at the zero test. Containing 0 is necessary but not enough: {z₁z₂ = 0} contains 0 but fails the adding test.
  • Thinking qubit states form a subspace. Unit vectors (length 1) don't: the zero vector isn't one, and adding two unit vectors usually doesn't give length 1. States live in the space ℂ²; they are not a subspace of it.
  • Checking independence with real numbers only. Over ℂ you may scale by complex numbers, so (i, −2) = i·(1, 2i) is dependent on (1, 2i), even though no real multiple works.
  • Mixing up "spans" and "is a basis". A basis must also be independent. If you know the dimension n and you have n vectors, checking just one of the two is enough.
  • Assuming a basis must be perpendicular. It doesn't have to be: (1, 0) and (1, 1) are a basis of ℂ² too. Orthonormal bases are just the most convenient.
