Q14Answer (A) 3

For u = (1, i)T and v = (2, i)T, the inner product ⟨u, v⟩ equals

  • A3
  • B1
  • C2 + i
  • D3i
Solution
⟨u, v⟩ = conj(u₁)·v₁ + conj(u₂)·v₂ (conjugate the first vector) = conj(1)·2 + conj(i)·i = 1·2 + (−i)·i = 2 − i² = 2 + 1 = 3 (A) Forgetting the conjugate gives 2 + i·i = 2 − 1 = 1, which is trap (B).

Quantum link: ⟨φ|ψ⟩ is exactly this computation. The probability of measuring state φ when the system is in ψ is |⟨φ|ψ⟩|².

Q15Answer (C) 1/√7

For which c > 0 is c·(1 + i, 2, i)T a unit vector?

  • A1/√5
  • B1/7
  • C1/√7
  • D1/√3
Solution
‖x‖² = |1+i|² + |2|² + |i|² (use the modulus squared of each entry, not the square) = (1² + 1²) + 4 + 1 = 2 + 4 + 1 = 7 ‖x‖ = √7, so c = 1/‖x‖ c = 1/√7 (C) Trap: squaring entries directly gives (1+i)² + 4 + i² = 2i + 4 − 1, which isn't even real.

Quantum link: this is normalising a 3-level state (a "qutrit"). The squared moduli 2/7, 4/7, 1/7 are the measurement probabilities and add to 1.

Q16Answer (B) −2 − 4i

Suppose ⟨u, v⟩ = 2 − i. Then ⟨iu, 2v⟩ equals

  • A2 + 4i
  • B−2 − 4i
  • C−2 + 4i
  • D4 − 2i
Solution

Rule: a scalar pulled out of the first slot gets conjugated; a scalar pulled out of the second slot comes out as is: ⟨au, bv⟩ = ā·b·⟨u, v⟩.

⟨iu, 2v⟩ = conj(i) · 2 · ⟨u, v⟩ = (−i)(2)(2 − i) = −2i(2 − i) = −4i + 2i² = −4i − 2 = −2 − 4i (B) Not conjugating gives 2i(2 − i) = 2 + 4i, which is trap (A).
Q17Answer (D) (2√2, √2)

The coordinates of v = (3, 1)T in the orthonormal basis {h₊, h₋} are

  • A(3, 1)
  • B(4, 2)
  • C(√2, 2√2)
  • D(2√2, √2)
Solution

Idea: in an orthonormal basis, each coordinate is just an inner product with that basis vector. No equations to solve.

h₊ = (1/√2)(1, 1), h₋ = (1/√2)(1, −1) c₊ = ⟨h₊, v⟩ = (1/√2)(3 + 1) = 4/√2 = 2√2 c₋ = ⟨h₋, v⟩ = (1/√2)(3 − 1) = 2/√2 = √2 (c₊, c₋) = (2√2, √2) (D) Check: 2√2·h₊ + √2·h₋ = (2, 2) + (1, −1) = (3, 1) ✓

Quantum link: h₊ and h₋ are the |+⟩ and |−⟩ states (the X basis). Changing basis like this is what "measuring in the X basis" means; H converts between |0⟩,|1⟩ and |+⟩,|−⟩.
