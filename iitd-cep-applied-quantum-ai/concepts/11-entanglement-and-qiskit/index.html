Entanglement and your first Qiskit circuit

Two qubits whose results always agree, built from one H gate and one CNOT, then run on a simulator in about a dozen lines of Python.

Back to basics: independent coins and the times-table grid

Toss two fair coins that don't affect each other. The chance of a pair of results is the first chance times the second chance. Lay all four pairs in a 2×2 grid, and every cell is "its row number × its column number", like a school times table.

P(heads, heads) = 1/2 × 1/2 = 1/4 P(heads, tails) = 1/2 × 1/2 = 1/4 (the other two cells are also 1/4)

A times-table grid has a quick test. Multiply the two diagonal corners, then the two other corners. If the grid came from "row × column", the answers are always equal.

Tiny example: is the grid [[2, 6], [1, 3]] a times table?

diagonal corners: 2 × 3 = 6 other corners: 6 × 1 = 6 6 = 6, so yes. Rows (2, 1) times columns (1, 3): 2 × 1 = 2, 2 × 3 = 6 1 × 1 = 1, 1 × 3 = 3 ✓

This is the 2×2 determinant from the eigenvalues concept in disguise: a·d − b·c = 0 means "it is a times table".

The idea

Some two-qubit states are just "qubit A's state ⊗ qubit B's state": their amplitude grid is a times table, and each qubit has its own story. These are product states. Other states cannot be split that way at all: the grid fails the corner test, so the only honest description is of the pair together. These are entangled. The Bell state is the simplest one: each qubit alone looks like a fair coin, yet the two always land the same way.

The circuit, step by step

Product or entangled? Look at the grid

The key formula

|Φ⁺⟩ = (|00⟩ + |11⟩) / √2

Read it aloud: "ket phi-plus equals, open bracket, ket zero-zero plus ket one-one, close bracket, all over root two."

In plain words: half the time you read both qubits as 0, half the time both as 1, never a mix. As a column (order 00, 01, 10, 11) it is (1/√2, 0, 0, 1/√2).

Worked example: build the Bell state by hand

Step 1. Both qubits start at 0.

state = |0⟩ ⊗ |0⟩ = |00⟩ as a column (00, 01, 10, 11): (1, 0, 0, 0)

Step 2. H acts on q0 only. From the gates concept, H|0⟩ = (|0⟩ + |1⟩)/√2.

|0⟩ ⊗ |0⟩ → (|0⟩ + |1⟩)/√2 ⊗ |0⟩ = (|0⟩⊗|0⟩ + |1⟩⊗|0⟩)/√2 = (|00⟩ + |10⟩)/√2 as a column: (1/√2, 0, 1/√2, 0)

Step 3. CNOT with control q0, target q1. Rule: if q0 is 1, flip q1. Apply it to each piece separately.

|00⟩: q0 is 0, leave q1 alone → |00⟩ |10⟩: q0 is 1, flip q1 (0 → 1) → |11⟩ (|00⟩ + |10⟩)/√2 → (|00⟩ + |11⟩)/√2 as a column: (1/√2, 0, 0, 1/√2)

Step 4. Measure. Each probability is the amplitude squared.

P(00) = (1/√2)² = 1/2 P(01) = 0² = 0 P(10) = 0² = 0 P(11) = (1/√2)² = 1/2

Check: 1/2 + 0 + 0 + 1/2 = 1 ✓ (the probabilities add up to 1)

Corner test: a × d = 1/√2 × 1/√2 = 1/2, b × c = 0 × 0 = 0, and 1/2 ≠ 0, so the result is entangled ✓

What 1000 shots look like

Common mistakes

  • "50/50 results mean entangled." Not by itself. |+⟩⊗|+⟩ gives all four outcomes at 1/4 each and is a plain product state. Entanglement shows up in how the two results agree, not in either result alone.
  • Expecting exactly 500 and 500. Counts come from random shots, so a run like 488 / 512 is normal. With 1000 shots the typical wobble is about 16 either side of 500.
  • Mixing up Qiskit's bit order. Qiskit prints labels with q0 on the right: '01' means q1 = 0, q0 = 1. For the Bell state it makes no difference (00 and 11 read the same both ways), but it will matter on other circuits.

Practice question

Run the Bell circuit (H on q0, CNOT q0 → q1, measure both) for 1000 shots. Confirm that 00 and 11 each appear about 500 times and that 01 and 10 never appear. Then explain in one line why 01 and 10 never appear.

Show answer

Expected counts are the number of shots times each probability (from the worked example):

00: 1000 × 1/2 = 500 01: 1000 × 0 = 0 10: 1000 × 0 = 0 11: 1000 × 1/2 = 500

A real run gives numbers near 500, not exactly 500. How near? The typical wobble for a fair coin is √(shots × 1/2 × 1/2):

1000 × 1/2 × 1/2 = 1000 × 1/4 = 250 √250 ≈ 15.8

So most runs land within about 2 × 15.8 ≈ 32 of 500, roughly 468 to 532. A run on this page's computer gave {'11': 512, '00': 488}, and 488 + 512 = 1000.

One-line reason: after the CNOT the state is (|00⟩ + |11⟩)/√2, which has amplitude 0 on |01⟩ and |10⟩, and 0² = 0, so the two qubits always read the same.

Check: 500 + 0 + 0 + 500 = 1000 shots ✓

Your first Qiskit circuit

In a terminal, install once: pip install qiskit qiskit-aer. Then run this script. Tested today with Qiskit 2.5 and Qiskit Aer 0.17.

bell.py
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator

qc = QuantumCircuit(2, 2)        # 2 qubits, 2 classical bits
qc.h(0)                          # H on q0
qc.cx(0, 1)                      # CNOT: control q0, target q1
qc.measure([0, 1], [0, 1])       # q0 -> bit 0, q1 -> bit 1
print(qc.draw())

sim = AerSimulator()
counts = sim.run(transpile(qc, sim), shots=1000).result().get_counts()
print(counts)                    # e.g. {'11': 512, '00': 488}
assert set(counts) <= {"00", "11"}   # no 01 or 10
