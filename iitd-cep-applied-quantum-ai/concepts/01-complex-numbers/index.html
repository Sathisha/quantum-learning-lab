Complex numbers

Every qubit is described by complex numbers. Today you learn to read them, draw them, and turn them into an angle and a length.

Back to basics

Pythagoras. In a right-angled triangle with short sides a and b, the long side (hypotenuse) c obeys c² = a² + b², so c = √(a² + b²).

Sine and cosine (SOH CAH TOA). For the angle θ at one corner: sin θ = opposite ÷ hypotenuse, cos θ = adjacent ÷ hypotenuse, tan θ = opposite ÷ adjacent.

Degrees and radians. 180° = π rad, so 90° = π/2, 45° = π/4.

Tiny example: a triangle with sides a = 3 (across) and b = 4 (up). c = √(3² + 4²) = √(9 + 16) = √25 = 5 sin θ = opposite ÷ hypotenuse = 4 ÷ 5 = 0.8 cos θ = adjacent ÷ hypotenuse = 3 ÷ 5 = 0.6 check: 0.6² + 0.8² = 0.36 + 0.64 = 1 ✓

The idea

No ordinary number squares to give −1, so mathematicians invented one, called i, and declared i² = −1. A complex number a + bi is then just a point on a flat plane: a steps across, b steps up. You can describe the same point a second way, by its length r and its angle θ. Quantum computing uses both descriptions all the time, and Euler's formula is the bridge between them.

Pictures

Key formula

e^(iθ) = cos θ + i·sin θ
Read it aloud: "e to the i theta equals cos theta plus i sine theta."
so any z = a + bi can be written z = r·e^(iθ), with r = |z| = √(a² + b²)
Read it aloud: "zed equals r e to the i theta, where r, the mod of zed, is the square root of a squared plus b squared."

Worked example: z = 3 + 4i

1. Real and imaginary parts a = 3, b = 4 2. Conjugate: flip the sign of b z̄ = 3 − 4i 3. Modulus (length) by Pythagoras |z| = √(a² + b²) = √(3² + 4²) = √(9 + 16) = √25 = 5 4. Angle (a is positive, so arctan gives the right angle) θ = arctan(b ÷ a) = arctan(4 ÷ 3) = arctan(1.3333…) ≈ 0.9273 rad ≈ 0.9273 × (180 ÷ π)° ≈ 53.13° 5. Polar form z = 5·(cos 53.13° + i·sin 53.13°) = 5·e^(i·0.9273) Check 1: turn the polar form back into a + bi 5 × cos 53.13° = 5 × 0.6 = 3 ✓ (that's a) 5 × sin 53.13° = 5 × 0.8 = 4 ✓ (that's b) Check 2: z times its conjugate should be |z|² (3 + 4i)(3 − 4i) = 3·3 + 3·(−4i) + 4i·3 + 4i·(−4i) = 9 − 12i + 12i − 16i² = 9 − 16·(−1) (because i² = −1) = 9 + 16 = 25 = 5² ✓

Common mistakes

  • Forgetting i² = −1. In (3 + 4i)(3 − 4i) the last term is −16i², which is +16, not −16. The answer is 25, not −7.
  • Putting the i inside the modulus. |3 + 4i| uses only the numbers a = 3 and b = 4: √(9 + 16) = 5. Never √(9 + (4i)²) = √(9 − 16).
  • Degrees vs radians, and the wrong quadrant. NumPy's np.angle returns radians (0.9273, not 53.13). And arctan(b ÷ a) alone is only right when a is positive; for a point on the left half (a negative), add 180°. Draw the point first and look.

Practice

Write z = (1 + i)/√2 in polar form, and show its modulus is 1.

Show answer
1. Split into real and imaginary parts z = 1/√2 + i·(1/√2) a = 1/√2 ≈ 0.7071, b = 1/√2 ≈ 0.7071 2. Square each part a² = (1/√2)² = 1² ÷ (√2)² = 1 ÷ 2 = 1/2 b² = 1/2 (same working) 3. Modulus |z| = √(a² + b²) = √(1/2 + 1/2) = √1 = 1 ✓ modulus is 1 4. Angle (a and b both positive, so top-right quarter) θ = arctan(b ÷ a) = arctan(0.7071 ÷ 0.7071) = arctan(1) = 45° = π/4 rad 5. Polar form z = 1·(cos 45° + i·sin 45°) = e^(iπ/4) Check: cos 45° = sin 45° = 1/√2 ≈ 0.7071, which matches a and b So (1 + i)/√2 = e^(iπ/4): the point at 45° on the unit circle ✓

Check it in NumPy

Python writes i as 1j.

import numpy as np
z = (1 + 1j) / np.sqrt(2)
print(abs(z))                              # 1.0 (modulus)
print(np.angle(z), np.pi / 4)              # 0.785398... both (radians)
print(np.isclose(z, np.exp(1j * np.pi/4))) # True

Roots of unity add up to zero

The n solutions of zⁿ = 1 are 1, ω, ω², …, ω^(n−1) with ω = e^(2πi/n), evenly spaced on the unit circle. For n ≥ 2 they add up to 0.

n = 3: ω = e^(2πi/3) = cos 120° + i sin 120° = −1/2 + i√3/2 ω² = e^(4πi/3) = −1/2 − i√3/2 1 + ω + ω² = (1 − 1/2 − 1/2) + i(√3/2 − √3/2) = 0 + 0i Sum = 0. Algebraic proof: (ωⁿ − 1)/(ω − 1) = 0 because ωⁿ = 1.

Quantum link: the lecturer flagged this as the heart of the Quantum Fourier Transform (Module 2). Practice Q8 is the n = 5 case.

Phases: global vs relative, and interference

A phase is a complex number of size 1, e^(iφ). Multiplying by one never changes a size, but adding numbers with different phases changes the result:

ExampleCan you measure it?
Global phaseψ vs i·ψNo. Every amplitude is multiplied by the same e^(iφ), so every |amplitude|² stays the same, in every basis.
Relative phase(1, 1)/√2 vs (1, −1)/√2Yes. Both give 50/50 in the 0/1 basis, but in the ± basis one gives "+" every time and the other "−" every time.
