Q1Answer (C) −1

Let z = (1 + i)/(1 − i). Then z2026 equals

  • A1
  • Bi
  • C−1
  • D−i
Solution

Idea: to divide by a complex number, multiply top and bottom by its conjugate. That makes the bottom real.

z = (1+i)/(1−i) × (1+i)/(1+i) = (1+i)² / (1² + 1²) bottom: (1−i)(1+i) = 1 − i² = 2 = (1 + 2i + i²) / 2 = (1 + 2i − 1)/2 = 2i/2 = i So z = i. Powers of i repeat every 4: i, −1, −i, 1, … 2026 = 4 × 506 + 2 → i^2026 = i² = −1 z^2026 = −1 (C)

Quantum link: factors like i and −1 are phases. The S gate multiplies |1⟩ by i; applying S twice gives Z, which multiplies by −1.

Q2Answer z̄/4 (the option with the bar)

If |z| = 2, then 1/z equals

  • Az/4
  • Bz/2
  • Cz/4
  • D−z/4
Solution

Idea: z times its conjugate is a real number: z·z̄ = |z|². Rearranged, that gives a formula for 1/z.

z · z̄ = |z|² = 2² = 4 Divide both sides by 4z: z̄/4 = 1/z 1/z = z̄/4 Check with z = 2: 1/z = 1/2 and z̄/4 = 2/4 = 1/2 ✓. With z = 2i: 1/(2i) = −i/2 and z̄/4 = −2i/4 = −i/2 ✓ (plain z/4 would give +i/2 ✗).

The pasted text lost the bar, so I've marked (A) as the bar option. On your sheet, choose whichever of (A)/(C) shows z with a line over it.

Quantum link: conjugation is everywhere: the "bra" ⟨ψ| is the conjugate of the "ket" |ψ⟩, and probabilities are |α|² = α·ᾱ.

Q3Answer (D) i

(2 + i)/(1 − 2i) equals

  • A(4 + 5i)/5
  • B−i
  • C1
  • Di
Solution
Multiply top and bottom by the conjugate of the bottom, (1 + 2i): top: (2+i)(1+2i) = 2 + 4i + i + 2i² = 2 + 5i − 2 = 5i bottom: (1−2i)(1+2i) = 1 − 4i² = 1 + 4 = 5 (2+i)/(1−2i) = 5i/5 = i (D) Shortcut: i·(1−2i) = i − 2i² = 2 + i. So the top is exactly i times the bottom.

Trap: (A) is what you get if you forget that i² = −1 and write 2i² as +2.

Q4Answer (B) 64

(1 + i√3)6 equals

  • A−64
  • B64
  • C64i
  • D32
Solution

Idea: never expand a 6th power by hand. Convert to polar form, then use (r eiθ)ⁿ = rⁿ einθ (De Moivre).

length: r = √(1² + (√3)²) = √4 = 2 angle: tan θ = √3/1 → θ = 60° = π/3 (point is in the first quadrant) (2 e^{iπ/3})⁶ = 2⁶ · e^{i·6π/3} = 64 · e^{i2π} = 64 · 1 = 64 (B)
Q5Answer (C) 2e7iπ/6

A polar form of −√3 − i is

  • A2eiπ/6
  • B2e5iπ/6
  • C2e7iπ/6
  • D2e−iπ/6
Solution
length: r = √((−√3)² + (−1)²) = √(3+1) = 2 Both parts negative → third quadrant (bottom-left). Reference angle: tan α = 1/√3 → α = 30° = π/6 Third quadrant angle = 180° + 30° = 210° = 7π/6 −√3 − i = 2 e^{7iπ/6} (C)
Q6Answer (A)

Which of the following is not a solution of z³ = −27?

  • A(3/2)(−1 + i√3)
  • B(3/2)(1 + i√3)
  • C−3
  • D(3/2)(1 − i√3)
Solution
−27 = 27 e^{iπ}. Cube roots: length ∛27 = 3, angles (π + 2πk)/3: k=0: 3e^{iπ/3} = 3(1/2 + i√3/2) = (3/2)(1 + i√3) → (B) k=1: 3e^{iπ} = −3 → (C) k=2: 3e^{i5π/3} = 3(1/2 − i√3/2) = (3/2)(1 − i√3) → (D) (A) = (3/2)(−1 + i√3) = 3e^{i2π/3}; cubed: 27e^{i2π} = +27, not −27 (A) is not a solution
Q7Answer (D) 2π/3

Real numbers α, β satisfy |eiα + eiβ| = 1. A possible value of α − β is

  • Aπ/3
  • Bπ/2
  • Cπ
  • D2π/3
Solution

Idea: two unit-length arrows added together. Their sum's length depends only on the angle between them.

|e^{iα} + e^{iβ}| = |e^{iβ}| · |e^{i(α−β)} + 1| = |e^{iφ} + 1|, φ = α − β |e^{iφ} + 1|² = (cos φ + 1)² + sin²φ = 2 + 2cos φ Set = 1²: 2 + 2cos φ = 1 → cos φ = −1/2 → φ = 2π/3 (120°) α − β = 2π/3 (D) Other options: π/3 gives length √3, π/2 gives √2, π gives 0.

Quantum link: this is interference. Adding amplitudes with a phase difference φ gives |sum|² = 2 + 2cos φ: φ = 0 is fully constructive (4), φ = π is fully destructive (0).

Q8Answer (B) −1

Let ω = e2πi/5. Then ω + ω² + ω³ + ω⁴ equals

  • A0
  • B−1
  • C1
  • D4
Solution
ω⁵ = e^{2πi} = 1, and ω ≠ 1. Geometric series: 1 + ω + ω² + ω³ + ω⁴ = (ω⁵ − 1)/(ω − 1) = 0/(ω−1) = 0 So ω + ω² + ω³ + ω⁴ = 0 − 1 = −1 (B)

Quantum link: roots of unity are the building blocks of the Quantum Fourier Transform, and this exact cancellation is why QFT-based algorithms (like Shor's) concentrate probability on the right answers.

Q9Answer (A) 2 − 2i

The point 1 + i is rotated by 90° clockwise about the origin and its distance from the origin is doubled. The new point is

  • A2 − 2i
  • B−2 + 2i
  • C2 + 2i
  • D−2 − 2i
Solution
Anticlockwise 90° = multiply by i. Clockwise 90° = multiply by −i. Double the distance = multiply by 2. (1+i) × (−i) × 2 = (−i − i²) × 2 = (1 − i) × 2 = 2 − 2i (A)
Q10Answer (C) 2i sin θ

For z = eiθ with θ real, z − 1/z equals

  • A2 sin θ
  • B2 cos θ
  • C2i sin θ
  • D0
Solution
1/z = e^{−iθ} (on the unit circle, 1/z = z̄) z − 1/z = (cos θ + i sin θ) − (cos θ − i sin θ) = 2i sin θ (C) Companion fact: z + 1/z = 2 cos θ (that's option B, the trap).
